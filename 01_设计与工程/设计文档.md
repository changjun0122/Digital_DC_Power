## 1. 项目背景与设计动机

本项目不是单独做一个电源，而是**为了解决另一个项目卡住的问题**：驱动直流电机的小项目用 TB6612 作驱动芯片，电机需要 **6~12V** 供电，并且要做**堵转测试**（把电机轴固定住，观察堵转瞬间的电流与电源表现）。

手头能用的电源全部不满足：

| 现有方案 | 为什么不行 |
|---|---|
| 单片机开发板 5V 输出 | 电压不够 6~12V；5V 硬驱只会让电机转不起来甚至堵转，驱动芯片长时间过流发热，有损坏风险 |
| 充电宝 5V 输出 | 电压同样不够；更关键的是充电宝带**过流保护**，堵转瞬间电流骤增会直接触发保护断输出，测试根本做不完、也读不到峰值电流 |
| 5V 升压模块 | 升压后电流能力按比例打折，输入侧仍受充电宝 5V 与保护电路限制，堵转时一样会掉压断电 |

由此提炼出本电源板的四条设计约束：

1. 能输出落在 **6~12V** 范围内的电压；
2. 堵转瞬态大电流时**不能自己断电保护**，否则测不到数据；
3. 能**实时看到输出电流**，堵转峰值才有记录手段；
4. 出现异常时能**快速切断输出**，保护电机、驱动芯片和电源本身。

对应到方案上的四个决定：

- 用 **PD 充电头 + CH224K 诱骗** 取 5V / 9V / 12V，取代充电宝：充电头原生输出高压、额定电流大、协议协商后持续供电，不会因负载突变轻易断输出；
- 用 **10mΩ 采样电阻 + INA180** 做电流检测，配上 I2C 显示，专供堵转测试读电流；
- 用 **三路光耦固态开关** 做输出通断与档位选择（VBUS / 3.3V / 1.8V 三选一），由 MCU 控制，不做会误动作的硬件过流硬切断；
- 用 **STM32F070** 负责采样、显示、按键设置与档位选择。

> 这一段是本项目自己的设计依据，也是答辩 / 面试最该讲清楚的部分：先有问题和约束，才有这块板。

## 2. 需求指标

| 指标 | 目标值 | 说明 |
|---|---|---|
| 输入接口 | Type-C 16P | 一个口完成供电与电压协商 |
| 输入电压 | PD 5V / 9V / 12V 档位 | CH224K 与充电头协商；CFG1~3 接 MCU（PF0 / PF1 / PA1），可软件选档 |
| **输出电压** | **PD 档：5V / 9V / 12V**；辅助轨直出：**3.3V / 1.8V** | 落在 TB6612 电机所需的 6~12V 内；档位切换，**不是无级调压** |
| **最大持续输出电流** | **2A 设计目标** | 依据：常见 PD 充电头 9V/2A、12V/1.5~2A；采样电阻 10mΩ/2512 功耗余量足；ADC 量程对应 3.3A，留约 1.6 倍余量 |
| 瞬态能力 | 堵转峰值由 PD 充电头承担 | 本板不做硬件过流断电，避免误触发导致测不到峰值 |
| 系统电源 | +3.3V、+1.8V | 供 MCU、电流采样、显示与逻辑 |
| 电流检测 | 10mΩ 高侧采样 + INA180A3 | 折算 1V/A 进 ADC |
| 电压检测 | R3/R6 分压 → VOL_ADC | 分压比决定电压上限，见 5.3 |
| 人机交互 | 3 个按键 + I2C 显示（H4） | 设置档位 / 通断，显示电压电流读数 |
| 调试接口 | SWD（H3，3P） | 烧录与在线调试 |
| 板形 | 70 × 28 mm 双层，四角 M3 孔 | 便携、可固定 |

**设计边界（先写清不做什么）**

- **不提供 6V / 7V / 8V 连续可调**：PD 固定档位只有 5 / 9 / 12 / 15 / 20V，本板取 **5 / 9 / 12V 三档**覆盖需求，另有 3.3V / 1.8V 辅助轨可经开关直出；要无级调压需后级可调 DC-DC 或 PPS 协议，不在本版范围。
- **不使用 15V / 20V 档**：既超出 TB6612 驱动芯片的推荐供电范围，也超出电压采样的 ADC 量程（见 5.3）。
- 不做 AC-DC、不做隔离反激、不做恒压恒流的软件 PID 闭环；输出电压由 PD 档位决定，MCU 负责采样、显示、通断判断与保护。

## 3. 总体方案与电源树

```
PD 充电头 ── Type-C USB1
  ├─ CC1 / CC2 → R4,R5 = 5.1K 下拉 → 充电头识别为受电设备
  ├─ CH224K (U1) 协商 PD 档位（CFG1~3 ← MCU PF0/PF1/PA1）→ VBUS
  │
  ├─【辅助电源】TPS54331DR (U3) + L1 6.8uH + D1 B340A + C4/C5/C8/C9
  │              → +3.3V → TLV75718 (U2) → +1.8V
  │              → 供 STM32F070 (U4)、INA180 (U9)、显示器、逻辑
  │
  └─【输出通道】三路光耦固态开关 U6/U7/U8（GAQY212GHA），三条电源轨三选一
                 ├─ CON_VBUS (PA2) ← VBUS（PD 5 / 9 / 12V）
                 ├─ CON_3V3  (PA3) ← +3.3V 轨
                 └─ CON_1V8  (PA4) ← +1.8V 轨
                 → R1 10mΩ 高侧采样 → VOUT → 负载（TB6612 的 VM / 电机）
                    ├─ INA180A3 (U9) → CUR_ADC → U4 的 ADC → I2C 显示
                    └─ R3/R6 分压  → VOL_ADC → U4 的 ADC

信号链：采样 → STM32F070 ADC → I2C 显示；按键 → 设置 → 档位选择 / 光耦通断 / 保护判断
```

**为什么分成「辅助电源」和「输出通道」两条**：辅助电源只要一个干净的 3.3V 给芯片用；输出通道是要被测量、被开关、并且会承受电机堵转大电流的那一路。两者电流等级和噪声要求完全不同，混在一起开关噪声会串进 ADC，电流读数就会飘——而读数正是这个项目做堵转测试的目的。

**三路开关是「三选一」，不是并联分流**：U6/U7/U8 分别串在 VBUS、+3.3V、+1.8V 三条支路上，作为三条电源轨通往 VOUT 的独立闸门。软件按 `先全断 → 设档 → 等协商 → 只合目标路` 的顺序操作（`OpenPowerSwitch()`），任意时刻只有一路导通，即 break-before-make，避免两路电压源在输出端被同时接通而互相倒灌。三路开关共用后级 R1 采样与 VOUT，因此电流/电压采样电路只需要一套。

**为什么不做硬件过流断电**：充电宝就是因为过流保护把堵转瞬间的输出掐断了。本板改用「采样监测 → MCU 判断 → 光耦切断」的软保护，既能拿到完整的峰值电流数据，又能在真出问题时快速断开。

## 4. 器件选型理由

> 说明：电路实现基于参考教程 / 开源方案，不是从零做的器件横向对比。写简历、答辩时应如实表述为「基于参考方案，逐项复核原理与参数后采用」；第 1 节的需求与约束分析、以及按 9V/12V 档位适配电机供电，是本项目自己的设计决定。

| 器件 | 型号 | 作用 | 为什么这样选 |
|---|---|---|---|
| U1 | CH224K | PD 诱骗 / 档位选择 | 一颗芯片让普通 PD 充电头输出 9V 或 12V，靠 CFG 引脚定档，MCU 不用跑 PD 协议。直接对应「充电宝只有 5V 且会过流保护」这个痛点：充电头高压原生输出、额定电流大、协商后持续供电 |
| U3 | TPS54331DR | VBUS → 3.3V 降压 | 输入耐压覆盖 12V（及更高 PD 档）、输出 3A、内置 MOSFET，外围只需电感 + 续流二极管 + 分压电阻。用 LDO 从 12V 直降到 3.3V，压差全变成热，不可行 |
| L1 / D1 | 6.8µH / B340A | 储能与续流 | 电感按 TPS54331 典型应用取值；B340A 为 3A/40V 肖特基，开关关断时给电感电流提供回路 |
| C4/C5、C8/C9 | 4.7µF / 47µF | 输入、输出滤波 | 按数据手册典型值配置，抑制开关纹波 |
| R10/R11、C13/C14/R12 | 10.2K / 3.24K / 29.4K | FB 分压与环路补偿 | 分压定 3.3V 输出；R12 与 C13/C14 构成 COMP 脚补偿网络，保证环路稳定 |
| U2 | TLV75718PDBVR | 3.3V → 1.8V | 固定输出 LDO，无需分压电阻；纹波小，适合给对噪声敏感的部分供电 |
| U4 | STM32F070F6P6 | 主控 | M0 内核，带多路 ADC 与足够 IO，TSSOP-20 手焊友好、成本低。本板只需采样 + 显示 + 按键 + 几路开关，用不到 F103 的性能 |
| U9 + R1 | INA180A3 + 10mΩ / 2512 | 电流检测 | INA180 是专用电流检测放大器，A3 版本增益固定 100 倍，省掉自己搭运放和配精密电阻；10mΩ 在 1A 时只损耗 10mW，2512 封装功率余量足。**这是堵转测试能读到电流的关键** |
| U6/U7/U8 | GAQY212GHA ×3 | 输出通道开关 | 光耦型固态开关：MCU 低压信号控制输出通断，控制侧与功率侧电气隔开，电机端的干扰与浪涌不容易打坏 MCU。三路分别串在 VBUS / +3.3V / +1.8V 三条支路上，由软件互斥选通（见 3 节） |
| R3 / R6 | 10K / 3.3K | 输出电压分压 | 把 VOUT 降到 ADC 量程内，分压比同时决定了本板的电压上限（见 5.3）。**注意：R5 是 CC 下拉，不是分压电阻** |
| R4 / R5(CC) | 5.1K ×2 | CC 下拉 | Type-C 规范 Rd 标称值，CC1/CC2 各一颗，告诉充电头「我是受电设备，先给 5V」 |
| R16 / R17 | 4.7K | I2C 上拉 | 显示屏总线所需 |
| R13~R15 | 100Ω | 光耦输入限流 | 从 3.3V 给光耦 LED 限流，MCU 拉低点亮 |
| USB1 | Type-C 16P | 取电口 | 只用 VBUS 与 CC 脚，不接 USB 数据，16P 够用且比 24P 好焊 |

## 5. 关键计算

**5.1 3.3V 反馈分压**
TPS54331 的 FB 基准为 0.8V，R10 = 10.2K、R11 = 3.24K：

```
V(+3.3V) = 0.8 × (1 + 10.2 / 3.24) = 3.32V ≈ 3.3V
```

**5.2 电流采样灵敏度（堵转测试的核心换算）**
R1 = 10mΩ，INA180A3 增益 = 100 V/V：

```
V(CUR_ADC) = I × 0.01Ω × 100 = I × 1 V/A
```

即 **1A 对应 1V**。3.3V 满量程的 ADC 理论可测到 3.3A，按 2A 设计目标留约 1.6 倍余量。采样电阻功耗 `P = I²R`，2A 时仅 40mW，2512 封装足够。调试时用万用表 + 电子负载验证这条线性关系即可。

**5.3 电压采样分压比 —— 决定了本板能用到哪一档**
R3 = 10K 上拉、R6 = 3.3K 下拉：

```
分压比 = 3.3 / (10 + 3.3) = 0.248
VOUT = 5V  → VOL_ADC = 1.24V
VOUT = 9V  → VOL_ADC = 2.23V
VOUT = 12V → VOL_ADC = 2.98V   ✓ 在 3.3V 量程内
ADC 满量程对应 VOUT ≈ 3.3 / 0.248 = 13.3V
```

所以本板按 **12V 上限**设计：15V / 20V 档会让 ADC 超量程（且超出 TB6612 推荐供电范围），不使用。这条计算把「6~12V 需求」和「PD 档位选择」锁死在一起，是选型与需求闭环的依据。

**5.4 CC 下拉**
5.1K 为 Type-C 规范 Rd 值，CC1 / CC2 各接一颗到 GND。

**5.5 功率边界与堵转工况**
按 2A 持续设计：采样电阻功耗 40mW、INA180 余量充足，主要瓶颈在 PD 充电头额定输出、光耦导通损耗与 VOUT 铜箔载流能力，因此布线阶段需保证 VOUT 主干铜箔按 ≥2A 设计。堵转瞬间电流可达正常运行数倍，该瞬态由充电头自身限流承担，本板负责把峰值如实采样并显示出来，不做硬件断电。

## 6. 接口与主要网络

| 接口 / 网络 | 用途 |
|---|---|
| VBUS、VOUT、+3.3V、+1.8V、GND | 电源主干 |
| CC1 / CC2 | Type-C 受电识别，R4/R5 = 5.1K 下拉 |
| CFG1 / CFG2 / CFG3 | CH224K 档位配置，接 MCU：PF0 / PF1 / PA1，推挽输出 |
| USBDP / USBDN | Type-C 数据脚，本板不用，保留 |
| IN1+、IN1−、CUR_ADC、VOL_ADC | 采样电阻两端、电流 / 电压 ADC（PA0 / PA5） |
| CON_VBUS / CON_3V3 / CON_1V8 | 三路输出开关控制，PA2 / PA3 / PA4，**低电平导通** |
| I2C1_SDA / I2C1_SCL | 显示屏（H4，4P），R16/R17 上拉 |
| SWDIO / SWCLK / NRST | 烧录调试（H3，3P）；NRST 经 10K 上拉 + 100nF 复位 |
| SW1 / SW2 / SW3 | 三个设置按键，另一端接 GND，按下接地：PB1 / PA7 / PA6，内部上拉 |
| H1 / H2 | 6P 排针，输出 / 扩展 / 测试 |

**6.1 档位真值表（固件 `setch224()` 与 `OpenPowerSwitch()` 实现）**

| 档位 | CFG1 (PF0) | CFG2 (PF1) | CFG3 (PA1) | 接通支路 | 输出电压 |
|---|---|---|---|---|---|
| `VOL_1V8` | 1 | 0 | 0 | CON_1V8 (PA4) | 1.8V（TLV75718 直出） |
| `VOL_3V3` | 1 | 0 | 0 | CON_3V3 (PA3) | 3.3V（TPS54331 直出） |
| `VOL_5V0` | 1 | 0 | 0 | CON_VBUS (PA2) | 5V（PD 协商） |
| `VOL_9V0` | 0 | 0 | 0 | CON_VBUS (PA2) | 9V（PD 协商） |
| `VOL_12V` | 0 | 0 | 1 | CON_VBUS (PA2) | 12V（PD 协商） |

> 1.8V / 3.3V 档不改 PD 档位，只切输出支路；CH224K 保持在 5V 档为 TPS54331 供电。
> 切档顺序固定为：全断 → 设 CFG → 等待 500ms 协商/泄放 → 只合目标支路。

## 7. 出板前检查清单（V1.2 出板时逐项执行）

- [ ] 所有网络连通、无飞线；电源极性、芯片耐压覆盖所选 PD 档位
- [ ] ADC 输入不超过 3.3V；电压分压比与电流增益核算无误（5.2 / 5.3）
- [ ] 采样电阻两端**各自单独引线**到 INA180，不与大电流共用一段走线（开尔文连接，否则测到的是走线压降而不是电阻压降）
- [ ] VOUT 主干铜箔按 ≥2A 载流设计；去耦电容靠近芯片电源脚；DC-DC 开关回路尽量短
- [ ] 光耦控制侧与功率侧间距足够；螺丝孔周围留禁布区，防止金属螺丝压到铜皮短路
- [ ] 确认 15V / 20V 档不会被误配置（超出 ADC 量程与驱动芯片耐压）
- [ ] DRC 全通过；BOM 位号、封装、数量与原理图一致

## 9. 设计边界与后续改进方向

本版定位是「给 TB6612 电机项目提供 5~12V、可测电流、不被过流保护掐断的供电」，同时把板上的 3.3V / 1.8V 辅助轨引出作为通用低压源。因此以下不在本版范围，留作实测后再按数据决定：

- 无级调压（需后级可调 DC-DC 或 PPS 协议）；
- 硬件过流硬切断与恒流恒压闭环；
- 更高电压档位（受电压采样分压比与驱动芯片耐压双重限制）；
- 输出纹波、满载温升、ADC 稳定性的实测结论 —— 由第 8 节的验证计划给出，不在此处凭空下结论。
