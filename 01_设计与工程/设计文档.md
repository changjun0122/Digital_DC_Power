## 1 背景与约束

来源是 TB6612 电机驱动项目：电机需 6~12V 供电，且要做堵转测试（固定电机轴，记录堵转电流与电源表现）。手上三种电源都不满足：

| 方案 | 不满足原因 |
|---|---|
| 开发板 5V 输出 | 电压不足，5V 驱不动电机，驱动芯片长时间过流发热 |
| 充电宝 5V 输出 | 电压不足；过流保护会在堵转瞬间切断输出，读不到峰值 |
| 5V 升压模块 | 升压后电流能力下降，输入侧仍受充电宝保护限制 |

由此确定四条约束：

1. 输出覆盖 6~12V；
2. 堵转瞬态不得自行断电；
3. 能实时读输出电流；
4. 异常时能快速切断。

对应四个决定：

- PD 充电头 + CH224K 取 5 / 9 / 12V，替代充电宝；
- 10mΩ 采样电阻 + INA180 测电流，I2C 显示；
- 三路光耦固态开关做输出通断与档位选择（VBUS / 3.3V / 1.8V 三选一）；
- STM32F070 负责采样、显示、按键与开关控制。

| 系统电源 | +3.3V、+1.8V | MCU、INA180、显示与逻辑 |

| 人机交互 | 3 按键 + I2C OLED（H4） | 设置档位与通断，显示电压电流 |
| 调试接口 | SWD（H3，3P） | 烧录与在线调试 |
| 板形 | 70 × 28 mm 双层，四角 M3 孔 | — |

设计边界：

- 不提供 6 / 7 / 8V 连续可调。PD 固定档位只有 5 / 9 / 12 / 15 / 20V，本板取前三档，另把 3.3V / 1.8V 辅助轨引出。无级调压需后级 DC-DC 或 PPS，不在本版。
- 不用 15 / 20V 档。超出 TB6612 推荐供电范围，也超出电压采样 ADC 量程（见 5.3）。
- 不做 AC-DC、隔离反激、恒压恒流闭环。输出电压由 PD 档位决定，MCU 只做采样、显示、通断与保护。

## 3 方案与电源树

```
PD 充电头 ── Type-C USB1
  ├─ CC1 / CC2 → R4,R5 = 5.1K 下拉 → 充电头识别为受电设备
  ├─ CH224K (U1) 协商 PD 档位（CFG1~3 ← MCU PF0/PF1/PA1）→ VBUS
  │
  ├─【辅助电源】TPS54331DR (U3) + L1 6.8uH + D1 B340A + C4/C5/C8/C9
  │              → +3.3V → TLV75718 (U2) → +1.8V
  │              → 供 STM32F070 (U4)、INA180 (U9)、显示、逻辑
  │
  └─【输出通道】三路光耦固态开关 U6/U7/U8（GAQY212GHA），三条电源轨三选一
                 ├─ CON_VBUS (PA2) ← VBUS（PD 5 / 9 / 12V）
                 ├─ CON_3V3  (PA3) ← +3.3V
                 └─ CON_1V8  (PA4) ← +1.8V
                 → R1 10mΩ 高侧采样 → VOUT → 负载（TB6612 的 VM / 电机）
                    ├─ INA180A3 (U9) → CUR_ADC → U4 ADC → I2C 显示
                    └─ R3/R6 分压  → VOL_ADC → U4 ADC

信号链：采样 → STM32F070 ADC → I2C 显示；按键 → 设置 → 档位选择 / 光耦通断 / 保护判断
```

辅助电源与输出通道分开，因为两者电流等级和噪声要求不同。辅助电源只需干净的 3.3V；输出通道要承受堵转大电流并被测量，混在一起开关噪声会串进 ADC，电流读数漂移。

三路开关是三选一，不是并联分流。U6/U7/U8 分别串在 VBUS、+3.3V、+1.8V 支路上，作为三条轨通往 VOUT 的闸门。`OpenPowerSwitch()` 按全断 → 设档 → 等协商 → 只合目标路的顺序操作，任意时刻只有一路导通（break-before-make），避免两个电压源在输出端互相倒灌。三路共用后级 R1 与 VOUT，采样电路只需一套。

不做硬件过流断电的原因：充电宝正是因此掐断了堵转瞬态。本板改为采样 → MCU 判断 → 光耦切断，既能取到峰值数据，也能在真出问题时断开。

## 4 器件选型

电路实现基于公开参考方案，非从零做器件横向对比；需求与约束分析、按 9V/12V 适配电机供电为自做。

| 器件 | 型号 | 作用 | 选择理由 |
|---|---|---|---|
| U1 | CH224K | PD 诱骗 / 档位选择 | 让普通 PD 充电头输出 5/9/12V，CFG 引脚定档，MCU 不跑 PD 协议 |
| U3 | TPS54331DR | VBUS → 3.3V | 输入耐压覆盖 12V，输出 3A，内置 MOSFET，外围仅需电感、续流二极管、分压电阻。12V 用 LDO 降到 3.3V 压差全变热，不可行 |
| L1 / D1 | 6.8µH / B340A | 储能与续流 | 按 TPS54331 典型应用取值；B340A 为 3A/40V 肖特基 |
| C4/C5、C8/C9 | 4.7µF / 47µF | 输入输出滤波 | 按手册典型值，抑制开关纹波 |
| R10/R11、C13/C14/R12 | 10.2K / 3.24K / 29.4K | FB 分压与环路补偿 | 分压定 3.3V；R12 与 C13/C14 构成 COMP 补偿网络 |
| U2 | TLV75718PDBVR | 3.3V → 1.8V | 固定输出 LDO，无需分压，纹波小 |
| U4 | STM32F070F6P6 | 主控 | M0，多路 ADC，TSSOP-20 手焊友好，成本低；本板用不到 F103 性能 |
| U9 + R1 | INA180A3 + 10mΩ/2512 | 电流检测 | 专用电流检测放大器，A3 增益固定 100 倍，免运放与精密电阻配对；10mΩ 在 1A 损耗 10mW，2512 功率余量足 |
| U6/U7/U8 | GAQY212GHA ×3 | 输出通道开关 | 光耦固态开关，控制侧与功率侧隔离，电机干扰不易打坏 MCU；三路分别串在三条支路，软件互斥选通 |
| R3 / R6 | 10K / 3.3K | 输出电压分压 | 将 VOUT 降到 ADC 量程内，同时决定电压上限（见 5.3）。R5 是 CC 下拉，非分压 |
| R4 / R5 | 5.1K ×2 | CC 下拉 | Type-C 规范 Rd 值，CC1/CC2 各一颗 |
| R16 / R17 | 4.7K | I2C 上拉 | 显示屏总线 |
| R13~R15 | 100Ω | 光耦输入限流 | 3.3V 侧限流，MCU 拉低点亮 |
| USB1 | Type-C 16P | 取电口 | 只用 VBUS 与 CC，不接数据；16P 比 24P 好焊 |

## 5 关键计算

### 5.1 3.3V 反馈分压

TPS54331 FB 基准 0.8V，R10 = 10.2K、R11 = 3.24K：

```
V(+3.3V) = 0.8 × (1 + 10.2 / 3.24) = 3.32V
```

### 5.2 电流采样灵敏度

R1 = 10mΩ，INA180A3 增益 100 V/V：

```
V(CUR_ADC) = I × 0.01 × 100 = I × 1 V/A
```

1A 对应 1V。3.3V 满量程理论可测 3.3A，对 2A 目标留 1.6 倍余量。采样电阻功耗 P = I²R，2A 时 40mW，2512 足够。标定时用电子负载记录 I 与 CUR_ADC 电压，验证线性。

### 5.3 电压采样分压比

R3 = 10K 上拉、R6 = 3.3K 下拉：

```
分压比 = 3.3 / (10 + 3.3) = 0.248
VOUT = 5V  → VOL_ADC = 1.24V
VOUT = 9V  → VOL_ADC = 2.23V
VOUT = 12V → VOL_ADC = 2.98V（在 3.3V 量程内）
ADC 满量程对应 VOUT ≈ 3.3 / 0.248 = 13.3V
```

故本板按 12V 上限设计，15V / 20V 档会让 ADC 超量程，且超出 TB6612 供电范围。分压比同时锁定了「6~12V 需求」与「PD 档位选择」。

### 5.4 CC 下拉

5.1K 为 Type-C 规范 Rd 值，CC1 / CC2 各接一颗到 GND。

### 5.5 功率边界

按 2A 持续：采样电阻 40mW，INA180 余量充足。瓶颈在 PD 充电头额定输出、光耦导通损耗与 VOUT 铜箔载流，故布线时 VOUT 主干按 ≥2A 设计。堵转峰值由充电头限流承担，本板只负责如实采样与显示，不做断电。

## 6 接口与主要网络

| 接口 / 网络 | 用途 |
|---|---|
| VBUS、VOUT、+3.3V、+1.8V、GND | 电源主干 |
| CC1 / CC2 | Type-C 受电识别，R4/R5 = 5.1K 下拉 |
| CFG1 / CFG2 / CFG3 | CH224K 档位配置，PF0 / PF1 / PA1，推挽输出 |

| I2C1_SDA / I2C1_SCL | 显示屏（H4，4P），R16/R17 上拉 |
| SWDIO / SWCLK / NRST | 烧录调试（H3，3P）；NRST 经 10K 上拉 + 100nF |
| SW1 / SW2 / SW3 | 按键，另一端接 GND：PB1 / PA7 / PA6，内部上拉 |
| H1 / H2 | 6P 排针，输出 / 扩展 / 测试 |

### 6.1 档位真值表

对应固件 `setch224()` 与 `OpenPowerSwitch()`：

| 档位 | CFG1 (PF0) | CFG2 (PF1) | CFG3 (PA1) | 接通支路 | 输出 |
|---|---|---|---|---|---|
| VOL_1V8 | 1 | 0 | 0 | CON_1V8 (PA4) | 1.8V，TLV75718 直出 |
| VOL_3V3 | 1 | 0 | 0 | CON_3V3 (PA3) | 3.3V，TPS54331 直出 |
| VOL_5V0 | 1 | 0 | 0 | CON_VBUS (PA2) | 5V，PD 协商 |
| VOL_9V0 | 0 | 0 | 0 | CON_VBUS (PA2) | 9V，PD 协商 |
| VOL_12V | 0 | 0 | 1 | CON_VBUS (PA2) | 12V，PD 协商 |

1.8V / 3.3V 档不改 PD 档位，只切输出支路，CH224K 留在 5V 档给 TPS54331 供电。切档顺序：全断 → 设 CFG → 等 500ms 协商与泄放 → 只合目标支路。

## 7 出板前检查清单

V1.2 出板时逐项执行，后续版本沿用。

- [ ] 网络连通无飞线；电源极性与芯片耐压覆盖所选 PD 档位
- [ ] ADC 输入不超过 3.3V；分压比与电流增益核算无误（5.2 / 5.3）

- [ ] VOUT 主干铜箔按 ≥2A 设计；去耦电容靠近芯片电源脚；DC-DC 开关回路尽量短
- [ ] 光耦控制侧与功率侧间距足够；螺丝孔周围禁布，防螺丝压铜短路
- [ ] 确认不会误配 15V / 20V 档
- [ ] DRC 全通过；BOM 位号、封装、数量与原理图一致

## 9 不在本版范围

- 无级调压（需后级 DC-DC 或 PPS）
- 硬件过流硬切断与恒压恒流闭环
- 更高电压档位（受分压比与 TB6612 耐压限制）
- 纹波、温升、ADC 稳定性的实测结论，见第 8 节
