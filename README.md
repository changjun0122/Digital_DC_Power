# Digital_DC_Power

基于 STM32F070 的数控直流电源板。为 TB6612 电机项目提供 5 / 9 / 12V 可切换、带电流显示的供电，支持堵转测试。

- 输入：Type-C，CH224K 诱骗 PD 5 / 9 / 12V
- 输出：VBUS / 3.3V / 1.8V 三路光耦开关互选，2A 设计目标
- 采样：10mΩ 高侧 + INA180A3，1V/A；R3/R6 分压测压
- 交互：I2C OLED + 3 按键，过流与欠压软保护
- 板卡：70 × 28 mm 双层，四角 M3 孔
