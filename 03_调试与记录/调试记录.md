# 调试记录

## D001 · 2026-11-26 · 硬件 V1.2 · SW2 无响应（接地脚虚焊）

**现象**

烧录后 SW2 无反应，SW1 / SW3 正常。程序读 PA7 原始电平，按下与松开读到同一值，不翻转。

**定位**

1. 同一份程序下 SW1 / SW3 正常，三键同为输入 + 内部上拉，扫描状态机无问题。故障限定在单键通路。
2. 万用表直流电压档，黑笔接 GND、红笔点 PA7：松开约 3.3V，按下仍 3.3V，未被拉低。
3. 断电，通断档分段测：按键两脚之间按下导通、松开断开（按键本体正常）；接地脚对板 GND 不通。

**根因**

接地脚虚焊，焊点未与焊盘熔合，按下时无法把 GPIO 拉低。

**处置**

补锡重焊。复测 PA7 按下约 0V，键值正常产生，功能恢复。

**结论**

- 排查顺序：读电平 → 电压档看是否被拉低 → 断电通断档分段 → 补焊复测。
- 手焊板功能调试前先做接地脚、电源脚通断普查，比逐功能试错快。
- 该缺陷与 V1.2 把铺铜由直连改回花焊盘同源：大面积铜皮散热快，单靠烙铁热量不足以充分润湿焊盘。
